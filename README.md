# Altersvorsorgedepot 2027 calculator

Interactive guide to the German Altersvorsorgedepot (AVD) pension reform, with a live subsidy calculator.

**Live:** https://thejavaguy.github.io/altersvorsorgedepot-calculator/

## What it covers

- State subsidy on your contributions, calculated live from your inputs
- Tax refund from the Sonderausgabenabzug, optionally including Solidaritätszuschlag and church tax (8 % or 9 %)
- Timeline of the reform, from proposal to law
- Contract types and where you can open one
- Costs, payout ages, inheritance and tax
- Links to the official sources (Bundestag, BMF, Bundesgesetzblatt)

Your inputs are saved in your browser's `localStorage` and never leave your device.

The site uses [Microsoft Clarity](https://clarity.microsoft.com/) to record anonymised sessions and heatmaps so the layout can be improved. Clarity masks input values by default. The project ID lives in the `<head>` of `index.html`.

## Run locally

It is a static site. Open `index.html` in a browser.

## Build the CSS

`tailwind.css` is generated by the Tailwind CLI from the classes used in `index.html` and `app.js`, and is committed so the site needs no build step to deploy. Rebuild it whenever you add or change Tailwind classes:

```sh
npm install
npm run build:css    # one-off minified build
npm run watch:css    # rebuild on every change while developing
```

Commit the regenerated `tailwind.css` together with the markup change.
